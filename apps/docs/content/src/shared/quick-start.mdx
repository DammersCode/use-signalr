## Requirements

- Node 20.19 or later.
- `@microsoft/signalr` 8, 9, or 10.
- A server with ASP.NET Core SignalR. The older ASP.NET SignalR for .NET Framework uses a different protocol and does not work with this client.
<Only in="react">
- React 19.
</Only>
<Only in="preact">
- Preact 10.20 or later, or Preact 11.
</Only>
<Only in="solid">
- Solid 1.7 or later.
</Only>
<Only in="svelte">
- Svelte 5.15 or later. Svelte 4 is not supported.
</Only>
<Only in="vue">
- Vue 3.3 or later.
</Only>
<Only in="angular">
- Angular 20, 21, or 22. The `rxjs-interop` entry point also needs `rxjs` 7.6 or later.
</Only>
<Only in="lit">
- Lit 3.
</Only>
